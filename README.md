# Контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание

Отдельная реализация учебного интернет-магазина на Bootstrap. Проект содержит главную страницу, каталог, страницу товара и форму заявки с общей адаптивной навигацией и единым визуальным стилем.

## Используемый фреймворк

Bootstrap 5.3.8.

## Способ подключения Bootstrap

Bootstrap подключён локально. Файлы фреймворка размещены в папке `vendor/bootstrap/`:

- `vendor/bootstrap/css/bootstrap.min.css`;
- `vendor/bootstrap/js/bootstrap.bundle.min.js`.

Собственный файл `css/custom.css` подключён после Bootstrap и используется для минимальных доработок оформления.

## Страницы проекта

- `index.html` — главная страница с hero-блоком, преимуществами и популярными товарами;
- `catalog.html` — каталог с карточками и модальным окном быстрой заявки;
- `product.html` — страница товара с характеристиками и accordion;
- `order.html` — форма заявки на Bootstrap.

## Реализованные компоненты

- `navbar` и мобильное раскрывающееся меню;
- адаптивная 12-колоночная сетка `container`, `row`, `col-*`, `g-*`;
- `card`;
- `btn`;
- `badge`;
- `alert`;
- `modal`;
- `form-control`;
- `form-select`;
- `input-group`;
- `form-check`;
- `accordion`;
- `breadcrumb`.

## Самостоятельные доработки

- Bootstrap подключён локально без CDN;
- добавлены отдельные страницы каталога, товара и заявки;
- реализованы модальное окно, accordion и хлебные крошки;
- карточки получили разные статусы и значки;
- форма использует разные типы Bootstrap-полей и адаптивную сетку;
- навигация единообразна на всех страницах.

## Как проверить

1. Открыть `index.html` и проверить адаптивную навигацию.
2. Открыть `catalog.html`, проверить карточки и модальное окно.
3. Открыть `product.html`, проверить таблицу и accordion.
4. Открыть `order.html`, проверить поля формы и обязательный чекбокс.
5. В DevTools проверить мобильную, планшетную и desktop-ширину.
6. Убедиться, что в консоли браузера нет ошибок.
